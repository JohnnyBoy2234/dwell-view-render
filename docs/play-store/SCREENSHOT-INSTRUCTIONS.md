# Feature Graphic Export Instructions

To export the feature graphic as a 1024×500px PNG:

1. Open `feature-graphic.html` in Chrome
2. Open DevTools (F12)
3. Click "Toggle device toolbar" (Ctrl+Shift+M)
4. Set custom dimensions: width **1024**, height **500**
5. Right-click the page → "Capture screenshot"
6. Save as `feature-graphic.png` in this directory

Upload `feature-graphic.png` to Play Console → Store listing → Feature graphic.
